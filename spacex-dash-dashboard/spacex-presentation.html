// 01 · Introduction

Project Overview
& Motivation

https://www.spacex.com/vehicles/falcon-9
  • Reusable Boosters: Falcon 9 first stages can land and fly again, which is a major reason SpaceX can reduce launch cost.
  • Key Variables: The analysis focuses on launch site, payload mass, orbit, and booster version.
  • Goal: Predict whether the first stage will land successfully and identify the patterns behind that outcome.
// 02 · Data Collection

Data Sources

SPACEX REST API

Collected Falcon 9 launch dates, sites, payloads, and outcomes from the SpaceX REST API.

WIKIPEDIA SCRAPING

Scraped Wikipedia to capture booster versions and launch history details.

COMBINED DATASET

Merged both sources into one cleaned dataset for analysis and modeling.

// 03 · Preprocessing

Data Wrangling
& Cleaning

  • Filtering: Kept Falcon 9 missions only.
  • Cleaning: Standardized formats and handled missing values.
  • Target Label: Converted landing outcome into a binary variable: 1 for success, 0 for failure.
  • Validation: Checked launch counts and outcome distributions before modeling.
// 04 · Analysis + Dashboard

EDA & Dashboard Highlights

SUCCESS RATE BY ORBIT TYPE
Orbit
  • Launch Site: CCAFS SLC-40 had the most launches, while KSC LC-39A delivered the strongest success record.
  • Payload: Medium payloads around 2,000-4,000 kg were the most recoverable.
  • Booster Version: Newer Falcon 9 FT and Block 5 boosters outperformed older versions.
  • Dashboard Use: Interactive filters made it easier to compare sites, payload ranges, and outcomes quickly.

// 08 · Reflections

Summary & Lessons Learned

  • End-to-End Workflow: This project covered collection, cleaning, visualization, and prediction in one pipeline.
  • Feature Insight: Payload, launch site, and booster version were the most useful signals for recovery success.
  • Dashboard Value: Interactive charts made the patterns much easier to explain than static plots alone.
  • Final Takeaway: XGBoost was the most balanced model after comparing both test accuracy and cross-validation performance.
